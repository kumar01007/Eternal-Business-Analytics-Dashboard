# Eternal Business Analytics Dashboard

An interactive Power BI dashboard designed to analyze business performance across Eternal's key consumer-facing verticals — **Zomato, Blinkit, and District**.

---

## 📌 Project Overview

Eternal operates across multiple consumer businesses including food delivery, quick commerce, and entertainment.

This project brings these verticals into a unified Power BI dashboard to provide a high-level view of business performance while allowing users to drill down into individual verticals.

The dashboard contains four major views:

- **Eternal Overview**
- **Zomato**
- **Blinkit**
- **District**

---

## 🎯 Objectives

- Track important business KPIs
- Analyze order, sales, and booking trends
- Identify high-performing categories
- Understand customer and product trends
- Compare performance across business verticals
- Build an interactive reporting solution for business decision-making

---

## 🛠️ Tech Stack

- Power BI
- DAX
- Power Query
- Excel / CSV
- Git & GitHub

---

## 📊 Dashboard Pages

### 1. Eternal Overview

Provides a consolidated view of business performance across the different Eternal verticals.

### 2. Zomato Analytics

Focuses on food delivery and restaurant-related metrics, including restaurant performance, ratings, customer preferences, and ordering trends.

### 3. Blinkit Analytics

Focuses on quick-commerce performance, including sales, product categories, outlet performance, and consumer trends.

### 4. District Analytics

Focuses on entertainment and booking-related performance across movies, events, and dining.

---

## 📈 Key Metrics

The dashboard focuses on metrics available in the underlying datasets, such as:

- Total Orders / Transactions
- Revenue / Sales
- Customers / Users
- Average Order Value
- Ratings
- Category Performance
- Booking Trends
- Growth Trends

> KPI availability depends on the underlying dataset.
